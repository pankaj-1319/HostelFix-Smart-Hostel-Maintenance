# HostelFix Pro

A modern, GitHub-ready Data Warehousing & Mining academic project for hostel maintenance.

## Features
- Responsive modern dashboard
- Complaint submission and tracking
- SQLite database
- Admin/demo login
- Searchable complaints table
- Pending / In Progress / Resolved workflow
- AI Prediction page
- J48-like Decision Tree
- Naive Bayes
- Linear Regression
- K-Means and Apriori practical material
- WEKA-compatible ARFF dataset
- Charts with Chart.js

## Run

```bash
pip install -r requirements.txt
python models/train_models.py
python app.py
```

Open `http://127.0.0.1:5000`.

## Demo login
Open `/login`. Any email and password work for the academic demo.
